# 桌面交互契约

从项目根目录运行 `uv run focusclockqt` 后打开简体中文主窗口。

| 控件 | 键盘操作及无障碍名称 |
| --- | --- |
| 分钟数 | `QSpinBox`，名称“专注时长（分钟）”。支持键入及上下键，范围为 1–180，仅待开始时可编辑。 |
| 剩余时间 | 只读 `QLineEdit`，名称“剩余时间”。通过 Tab 导航后可按需读取，显示分钟和秒。 |
| 当前状态 | 只读 `QLineEdit`，名称“当前状态”。值为待开始、运行中、已暂停或专注完成。 |
| 开始、暂停、继续、重置 | `QPushButton`，能通过 Tab 定位及空格触发。前三者按状态启用，重置始终可用。 |

Tab 顺序为分钟数、剩余时间、当前状态及可用按钮，Shift+Tab 逆向。操作导致焦点控件被禁用时，开始后转到“暂停”，暂停后转到“继续”，继续后转到“暂停”。重置后可直接导航至分钟数。自然完成时若焦点所在控件仍可用则保留焦点，若不可用则导航到当前状态。可用 Alt+F4 关闭窗口。

提交时先验证候选文本，再更新有效设置。无效时长保留上次有效设置，阻止开始，提供可见且能被 NVDA 读取的中文反馈。验证点击开始或键盘转移焦点时，控件自动纠正输入也不会静默启动。倒计时刷新不移动焦点，不主动发送每秒朗读事件。完成状态保留在窗口中，播放一次系统提示音，无论窗口是否在前台。后台主动播报由规范中的待澄清事项决定。
