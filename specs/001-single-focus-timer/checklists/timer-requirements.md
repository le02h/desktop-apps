# 需求质量检查清单：单次专注计时器

**用途**：供实现前审阅，检查规范是否完整、明确且可验收。  
**创建日期**：2026-11-21  
**功能**：[单次专注计时器规范](../spec.md)

**审阅归属**：由审阅者确认条目满足需求质量标准后标记 `[x]`。

## 状态、输入与边界

- [ ] CHK001 规范是否为待开始、运行中、已暂停和已完成定义了可用操作、转换条件、目标状态及剩余时间，并规定了无效或重复操作的结果？[完整性，规范 §状态转换、FR-003–005]
- [ ] CHK002 完成、重置和关闭的会话终止规则是否一致，包括到期与重置相邻发生时的优先次序、旧会话提示及重新启动的初始状态？[一致性，规范 §边界情况、FR-005–007、SC-005]
- [ ] CHK003 规范是否明确了默认 25 分钟、1–180 分钟整数范围及端点、可修改时长的状态，以及空值、非整数和越界值的处理与反馈？[边界覆盖，规范 §边界情况、FR-001–003、SC-002]

## 完成提示与无障碍

- [ ] CHK004 自然归零与恢复后到期是否采用一致的完成要求，包括零值、“专注完成”文本、每次会话仅一次提示音，以及静音或音频不可用时仍可获取的反馈？[一致性，规范 §边界情况、FR-006、SC-001、SC-006]
- [ ] CHK005 纯键盘需求是否覆盖设置、开始、暂停、继续、重置和关闭，并给出可验收的焦点顺序、可见焦点及控件禁用后的焦点处理标准？[可验证性，规范 §用户故事 3、FR-008、SC-004]
- [ ] CHK006 NVDA 需求是否明确应读取的控件信息、按需读取的剩余时间与状态，以及如何判定状态变化可察觉且没有逐秒自动播报？[可验证性，规范 §用户故事 3、FR-009、SC-004]

## 已确认规则与待验证事项

- [ ] CHK007 规范是否明确了睡眠和休眠提前恢复、到点或超期恢复、手动暂停后恢复的结果，并标明仍需 Windows 实测的通知和恢复行为？[覆盖，规范 §状态转换、FR-010、SC-006、假设]
- [ ] CHK008 后台完成时 NVDA 是否主动播报等未决需求，是否已明确标为待澄清，并与 NVDA、系统音频和电源通知的待技术验证事项区分？[歧义，规范 §假设]
