# 实现方案：单次专注计时器

**分支**：`pomodoro-qt` · **更新日期**：2026-11-21 · **规范**：[spec.md](spec.md)

## 摘要

在现有 Windows 桌面项目中实现一次可设置时长的专注会话。纯 Python 核心根据显式时间输入处理状态转换，Qt 界面负责输入、刷新、键盘焦点和提示。默认 25 分钟，允许 1–180 分钟。会话只存在于进程内存。

## 技术背景

- **语言与依赖**：Python 3.13、现有 PySide6、uv 和 uv_build。仅使用现有依赖与标准库。
- **平台**：Windows 桌面，使用 Windows Terminal 和 PowerShell 验证运行命令。睡眠、休眠和 NVDA 行为须在目标设备实测。
- **计时准确性**：运行期间根据清醒时钟截止点与当前时间的差值计算剩余量。约每 200 ms 由 QTimer 请求刷新，显示秒数改变才更新控件。以持续唤醒的 1 分钟会话误差不超过 1 秒为验收目标。
- **恢复策略**：清醒时间用于日常倒计时，包含挂起的单调时间只用于恢复时判定是否到点。提前恢复按冻结余量重建截止点，超期恢复走与自然归零相同的完成路径。
- **测试**：pytest 直接向核心传入可控制的读数，pytest-qt 向窗口注入同一套假时钟和提示音替身，验证真实控件、键盘操作和完成提示的触发次数。Ruff 检查代码。
- **范围**：单窗口、单会话。排除休息循环、历史统计、数据库、持久化、托盘及安装包。
- **待决定的产品行为**：后台是否主动通过 NVDA 播报完成仍待确认。已确认的状态查询、完成文本、音频及逐秒刷新静默可以独立实施。后台主动播报的实现与验收等待确认。

## 章程检查

| 原则 | 设计依据 |
| --- | --- |
| 无障碍优先 | 标准 Qt 控件、可见焦点、可访问名称、纯键盘路径及 Windows/NVDA 实测。 |
| 核心逻辑独立 | 状态机接收显式时间输入，单测无需 Qt 窗口或事件循环。 |
| 用户行为可验收 | 由规范的状态转换、界面契约和验收步骤定义；后台主动播报保留待确认。 |
| 自动化测试 | pytest 覆盖时长、状态边界、恢复及重复通知；pytest-qt 覆盖键盘、控件状态和提示触发。 |
| 简单实现 | 复用包布局、工具和入口命令，限定 Windows 适配层的职责，不引入后台线程或额外依赖。 |
| 中文优先 | 主窗口、状态、输入反馈及文档使用简体中文。 |

设计后复核：已确认范围符合六条原则。平台行为是否通过验收，以 Windows 真机和 NVDA 验证记录为准。
