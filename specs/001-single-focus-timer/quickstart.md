# 启动与验收

以下命令供实现完成后在 Windows Terminal 的 PowerShell 中从项目根目录运行。需要 uv、Python 3.13，手动无障碍验收还需 NVDA。

```powershell
uv sync --locked
uv run focusclockqt
```

窗口启动时应显示待开始和 25 分钟。实现时需将项目脚本映射为 `pomodoro:main`，并以 `uv sync --locked` 验证锁文件和入口一致。

```powershell
uv run python -m pytest -q
uv run ruff check src tests
```

1. **正常流程**：仅用键盘设为 1 分钟，完成一次暂停、继续和重置。再开始一次完整计时，用独立秒表测量从开始到显示“专注完成”的时间。系统持续唤醒且会话未暂停时，通过范围为 59–61 秒。核对归零、一次提示音和无自动后续阶段。重开应用核对恢复默认 25 分钟。
2. **边界**：测试 1 与 180 分钟、无效输入、运行和暂停时的设置锁定。自动化测试推进假时钟，覆盖延迟刷新、到期附近操作与重复完成，无需等待完整会话。
3. **NVDA**：按 [桌面交互契约](contracts/desktop.md) 验证 Tab 顺序、焦点、控件和值的朗读、完成状态可发现性，以及连续 10 秒无逐秒自动播报。记录前后台表现与 NVDA、Windows、PySide6 版本。
4. **电源恢复**：在支持相应电源状态的设备上分别测试睡眠和休眠。对每种状态分别验证到点前恢复、到点后恢复和暂停后恢复。检查一次提示音和零值，记录硬件、电源状态和观察结果。到点恰好相等的分支用可控时钟覆盖。

## NVDA 人工验收步骤

1. 启动 NVDA 后运行应用。用 Tab 和 Shift+Tab 往返，核对“专注时长（分钟）”“剩余时间”“当前状态”和可用按钮的名称、角色、数值或状态，确认焦点可见。
2. 清空时长，用 Tab 离开后尝试开始，确认仍为待开始，并能在时长字段读取中文错误说明。改为 1 分钟后导航到“开始”，按空格，确认焦点移到“暂停”。再用空格依次暂停、继续，核对焦点切换和状态值。
3. 运行时按需查看剩余时间与当前状态，再停在剩余时间字段 10 秒以上，记下 NVDA 是否随刷新反复朗读。让会话自然完成，核对剩余 00:00 和“专注完成”可按需读取。分别记录前台和后台是否有主动播报，后台策略仍待确认。
4. 用键盘重置并确认可重新编辑时长。用 Alt+F4 关闭并重启，检查回到待开始和 25 分钟。可用静音再走一次完成流程，确认完成状态仍可读取。

## 可控时钟验收用例

| 场景 | 推进方式 | 预期结果 |
| --- | --- | --- |
| 刷新延迟 | 开始 1 分钟会话，两种时钟都前进 7.5 秒后只触发一次刷新。 | 精确剩余 52.5 秒，界面显示 53 秒。 |
| 提前恢复 | 剩余 40 秒时挂起，只推进含挂起的时钟 10 秒，再恢复。 | 仍剩 40 秒，无提示音，后续清醒时间继续扣减。 |
| 到点恢复 | 剩余 40 秒时挂起，只推进含挂起的时钟 40 秒，再连续发送两次恢复通知。 | 第一次恢复即归零并完成，提示音总调用次数为 1。 |
| 手动暂停后恢复 | 剩余 40 秒时暂停，再模拟挂起与恢复。 | 状态仍为已暂停，剩余 40 秒，无提示音。 |
