# 数据模型

| 数据 | 内容及约束 |
| --- | --- |
| 专注设置 | 整数分钟，默认 25，范围 1–180。仅待开始可修改。 |
| 计时会话 | 至多一个。状态为待开始、运行中、已暂停、已完成。剩余量使用非负整数纳秒。 |
| 运行区间 | 开始、手动继续或提前唤醒后建立。保存清醒时钟截止点和含挂起时钟截止点。两个截止点分别由当前对应读数加剩余量得出。 |
| 挂起快照 | 运行中收到挂起事件时保存当前剩余量及含挂起时钟截止点。每次有效恢复只消费一次。它是内部字段，界面状态仍为运行中。 |
| 完成事件 | 由首次从运行中转入已完成产生，供界面触发提示声。重复刷新或恢复不会再次产生。 |

开始时以完整时长建立区间。运行时以清醒截止点减当前清醒时钟计算剩余量，并限制最小值为零。显示秒数向上取整，只有实际完成时才显示零。暂停时保存精确剩余量并清除区间，继续时建立新区间。提前恢复以挂起快照的剩余量建立新区间，达到或超过含挂起时钟截止点时进入已完成。重置清除区间和挂起快照并恢复完整时长。关闭丢弃所有会话内存。

核心接收显式时钟读数、操作和电源事件，提供当前状态、剩余量和一次性完成结果。界面操作与回调在同一 Qt 事件循环串行执行。暂停之前核对是否已自然到期。重置若先处理，废弃旧会话，旧回调不能补发提示。
